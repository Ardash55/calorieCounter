# Calorie Counter(v1.0)

## Что делает
Консольный калькулятор калорий: 
- Имеет возможность создания и изменения пользователя
- Класс пользователя включает в себя данные о поле, росте, весе, возрасте, уровне активности, целях и норме калорий пользоваателя
- Имеет класс сегодняшнего дня с автопроверкой даты и обновлением с наступлением нового дня
- Класс дня включает в себя три приема пищи с добавлением в каждый еды (название добавляет сам пользоваатель) и количества съеденных калорий, а также количество съеденных калорий и остаток от нормы калорий 
- Есть сохранение списка дней и вывод истории последних десяти
- Все данные сохраняются в память системы
- Есть проверки try catch на все вводы

## Ограничения
- Отсутствует база данных продуктов
- Отсутствует полноценный интерфейс 
- Нет БЖУ продуктов
- Нет выбора, сколько дней из истории посмотреть
- Нет возможности изменения или удаления приемов пищи
- Нет проверок try catch там, где программа может лечь без пользовательского ввода
